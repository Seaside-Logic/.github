# Seaside Logic

We build practical web products and open source developer tools on the Carolina coast.

## Open source

### [resAPI](https://resapi.dev)

Type-safe HTTP contracts for ReScript. Define an API once and share types and validation between clients and servers, with adapters for Hono and Express and support for Cloudflare Workers. Requests, responses, and application errors follow the same contract, without generated code.

resAPI is MIT licensed and currently in preview.

[Get started](https://github.com/Seaside-Logic/resapi/blob/main/docs/getting-started.md) · [Source code](https://github.com/Seaside-Logic/resapi) · [Report an issue](https://github.com/Seaside-Logic/resapi/issues)

### [rescript-radix](https://rescript-radix.dev)

Unofficial ReScript React bindings for Radix Primitives. Build with Radix's accessible, unstyled components using typed props and callbacks in ReScript. Radix handles interaction behavior, keyboard navigation, and focus management, while your application controls styling and composition.

rescript-radix is MIT licensed and includes documentation and live examples.

[Get started](https://rescript-radix.dev) · [Source code](https://github.com/Seaside-Logic/rescript-radix) · [Report an issue](https://github.com/Seaside-Logic/rescript-radix/issues)

## Products

### [QRacker](https://qracker.com)

A free QR code generator with custom colors, logos, and PNG or SVG downloads. Static codes are created in your browser, require no account, and never expire. Your content stays on your device.

### [Menu Cooker](https://menucooker.com)

A subscription service for restaurant menus that guests open with a QR code. Update prices, hide sold-out dishes, and add specials while keeping the same QR code.
